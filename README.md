# JATAPP – QC Logistik (Frontend)

Vite + React + TypeScript + Tailwind CSS 3.

    npm install
    npm run dev

Halaman: Scanner Paket, Database Scanner, Tugas Repack, Tracking PDA (placeholder),
Db. Referensi, Database All, Admin Panel. Mode gelap/terang tersimpan di localStorage.
Data masih mock di `src/data/mock.ts`; hubungkan ke backend/API AI Anda di tempat yang ditandai TODO.
